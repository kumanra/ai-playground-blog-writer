# AGENTS.md

This project is an AI newsletter workflow for writing practical guides, notes, and tutorials.

## Working rules
- Keep writing simple and direct.
- Use short paragraphs.
- Do not use corporate or academic language.
- Ask before changing the main structure.
- Check the final draft against anti_ai_writing_instructions.md.
